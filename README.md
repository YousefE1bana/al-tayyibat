# نظام الطيبات · Al-Tayyibat

دليل معلوماتي عربي مستقل لقواعد نظام الطيبات للدكتور ضياء العوضي. يتيح البحث في **385 طعامًا**، تصفح التصنيفات والقيود والبدائل، فحص المكونات، الوصفات، المحفوظات، المشتريات والطباعة. يدعم العربية وRTL والمظهرين الفاتح والداكن.

[الموقع العام](https://yousefe1bana.github.io/al-tayyibat/) · [ملاحظات المحتوى للمحررين](docs/content-observations.md)

> يعرض الموقع قواعد النظام وينسب الادعاءات إلى أصحابها؛ لا يثبت صحتها العلمية ولا يقدم نصيحة طبية شخصية. استشر مختصًا قبل تغيير علاج أو نظام غذائي مرتبط بحالة صحية.

![معاينة الدليل](public/social-preview.jpg)

## التطوير

استخدم Node.js 24 LTS أو إصدارًا متوافقًا ≥22.12:

```bash
npm install
npm run dev
```

يفتح Vite الموقع عادةً على `http://localhost:5173/al-tayyibat/`. يتوفر `start.bat` لتشغيله على Windows. استخدم `npm ci` لتثبيت مطابق لملف الاعتماديات.

```bash
npm run typecheck
npm run validate
npm run build
npm run preview
```

## التحقق والصيانة

| الأمر | الغرض |
| --- | --- |
| `npm run typecheck` | TypeScript strict |
| `npm run validate:baseline` | مقارنة محتوى الكتالوج ببصمة النسخة المراجعة، باستثناء الصور |
| `npm run validate:content` | الأعداد، IDs/slugs، الفئات، البدائل، الأطعمة المرتبطة، المراجع والروابط |
| `npm run validate:images` | الصور المحلية، الأسماء والمقاسات، التكرار، الملفات غير المستخدمة وسلامة صورة الدكتور |
| `npm run validate:search` | تطبيع البحث العربي واسترجاع أسماء الكتالوج |
| `npm run validate` | جميع المدققات السابقة |
| `npm run qa:browser` | فحص المتصفح الحقيقي من 390 إلى 1920 بالمظهرين، مع axe واختبارات لوحة المفاتيح والحركة المخففة |

ثوابت المحتوى: **385 طعامًا**، موزعة على **116 compatible / 103 conditional / 157 notRecommended / 4 disputed / 5 unknown**. تحسينات العرض لا تغيّر هذه الأعداد أو معنى القواعد. أي تعديل تحريري يحتاج مصدرًا واضحًا ومراجعة مستقلة وتحديثًا مقصودًا لبصمة `docs/catalog-baseline.json`؛ المدقق لا يكتب البيانات أو يعيد توليدها. التحقق البنيوي لا يحل الملاحظات الدلالية المسجلة في وثيقة المحتوى.

لفحص المتصفح، شغّل البناء ثم `npm run preview -- --host 127.0.0.1 --port 4173`. تستخدم سكربتات QA نسخة Google Chrome المثبتة. يمكن تثبيت Chromium عبر `npx playwright install chromium` وتغيير خيار `channel` عند الحاجة. يغيّر `QA_BASE_URL` عنوان الفحص. التقارير واللقطات تحفظ في `output/` المستبعد من Git.

- `node scripts/browser-interactions.mjs`: لوحة المفاتيح، الطباعة، فاحص المكونات وحالات الصورة البديلة.
- `node scripts/validate-live-assets.mjs`: مقارنة جميع ملفات النشر ببناء `dist/` الحالي، دون الاعتماد على manifests قديمة؛ العنوان الافتراضي هو الموقع العام.
- `node scripts/social-preview.mjs`: التقاط معاينة اجتماعية من الخطوط وصور المشروع المحلية، بعد تشغيل خادم المعاينة.

## البنية

React 19 · TypeScript · Vite 7 · Tailwind 4 · Framer Motion · Radix UI · Lucide · Fuse.js · HashRouter.

```text
src/components/     هيكل الواجهة والعناصر المشتركة
src/config/         إعدادات مالك المشروع
src/features/       الأطعمة والبحث والوصفات والإسناد والمظهر
src/pages/          صفحات الموقع والطباعة و404
src/data/           الكتالوج والمراجع وسجل الصور
src/hooks/          التخزين المحلي والمجموعات وبيانات الصفحة
src/lib/            البحث والحالات والحركة والتحقق
public/             الصور والخطوط وبيانات النشر
assets/doctor/      أصل الصورة الثانوية غير المنشور
scripts/            المدققات وأدوات QA المدعومة
docs/              ثوابت الكتالوج وملاحظات التحرير
.github/workflows/  التحقق والنشر
```

الهوية البصرية تجمع Retro Neo-Brutalism وTerminal Editorial، بحدود صلبة وظلال مزاحة وألوان دافئة وخط IBM Plex Sans Arabic. الحركة قصيرة وتحترم `prefers-reduced-motion`.

لا يحتاج الموقع إلى backend أو حسابات أو قاعدة بيانات سحابية. تحفظ المحفوظات والمشتريات والمظهر على جهاز الزائر، ويظل الموقع قابلًا للاستخدام عند تعذر التخزين. لا ترسل هذه البيانات إلى خادم.

## النشر

الاستضافة المعتمدة **GitHub Pages**. الدفع إلى `main` يشغّل `.github/workflows/release.yml`: `npm ci` ثم TypeScript والتحقق والبناء والنشر. طلبات السحب تتحقق دون نشر. إعداد المستودع: **Pages → Source → GitHub Actions**.

البناء في `dist/` والمسار الافتراضي في Vite هو `/al-tayyibat/`. تعمل روابط مثل `#/foods/pasta` عند التحديث دون قواعد إعادة كتابة. استخدم خادم HTTP للمعاينة بدل فتح ملف البناء مباشرةً من القرص.

لنطاق جذر آخر، اضبط `VITE_BASE_PATH=/` أثناء البناء وحدّث canonical وOpen Graph وrobots وsitemap. يعمل المشروع أيضًا على Vercel أو Cloudflare Pages بالأمر `npm run build` ومجلد `dist`. لا يتطلب النشر أسرارًا أو ميزات مدفوعة.

تستخدم بيانات SEO عنوانًا canonical واحدًا؛ مسارات hash ليست صفحات مستقلة في sitemap.

## سياسة المحتوى والصور

تبقى المراجع في `src/data/sources.ts` لخدمة الإسناد والتحقق التحريري، وتظهر الإحالات بجوار المحتوى دون قسم مصادر عام. لا تضف مؤهلات أو ادعاءات طبية أو قواعد غذائية من دون توثيق.

لكل طعام صورة محلية مستقلة باسم `public/images/foods/<food-id>.jpg`، JPEG بنسبة 4:3 ومقاس 1200×900. التغطية الحالية **385/385**. تتضمن الصور أصولًا مقدمة وصورًا مولدة راجعتها المرحلة السابقة؛ هي توضيحية ولا تثبت تركيب الطعام أو منشأه. لا تضف صور stock بعيدة أو ادعاء ترخيص غير موثق. السجلات السابقة محفوظة في تاريخ Git؛ أدوات الترحيل القديمة ليست ضمن workflow المدعوم.

صورة الدكتور الأساسية `public/images/doctor/portrait.jpg` محمية ببصمة المدقق. الأصل الثانوي محفوظ دون تعديل في `assets/doctor/secondary-original.jpg` لمرحلة لاحقة؛ لا يُنشر حاليًا. لا تولد أو تعدّل الوجه.
